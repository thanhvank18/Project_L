## Typography

### Elite landing

Playfair Display with Georgia and serif fallbacks carries headings; Inter with a sans-serif fallback carries body text and controls. Local font files supply Playfair weights 600/700 and Inter weights 400/600 with Vietnamese, Latin and Latin Extended coverage. Headings use weight 700, with selected italic heading emphasis at 600. The frontmatter elite-display, elite-headline, elite-title, elite-body and elite-action roles record the desktop hierarchy.

At 960px and below, the hero size becomes clamp(48px, 7.4vw, 68px). At 600px and below, it becomes clamp(38px, 10.1vw, 54px) with line height 1.16; section headings become 34px with line height 1.26. Hero supporting text is 18px/1.7 on desktop and 16px/1.75 on mobile. Contact fields grow from 14px to 16px on mobile. Navigation uses Inter 600 at 13px. Source section labels are preserved as reference content; their treatment is not a reusable house typography role.

### Learning portal and native login

Be Vietnam Pro carries both task and sign-in interfaces, using the existing self-hosted Vietnamese-capable family. The mis-headline and mis-title roles define portal page and section headings; compact dashboard headings use mis-dashboard-title. The mis-body, mis-action, mis-label, mis-status, mis-caption and mis-metric roles cover work text, tables, supporting labels and tabular metric values. At 760px, shell page headings reduce to 24px; at 600px, dashboard metrics reduce to 1.5rem and dashboard headings to 0.9375rem. Content views preserve their local 1.05rem headings and 0.9375rem reading text. The retained lp-action, lp-label and lp-status roles describe task controls rather than the replaced navigation shell.

Native login uses login-headline and login-body; its main heading reduces to 1.5rem at 600px. Credential inputs use 1rem for readable entry. Both interfaces retain labeled controls and explicit status text. The MIS shell does not inherit landing serif display typography.

Shared MIS form fields grow to 16px at 760px. Retained learning fields grow to 1rem at 720px; Reading/Writing textareas reach 1rem at 820px.
